Learning sheet · Level 1, batch 4 · S4.03

Counting without listing: the multiplication rule.

How many four-digit codes exist, and how many ways are there to arrange five books? In many probability problems, counting comes first. With an imaginary tree of choices, we meet the multiplication rule, factorials and arrangements, and learn when order matters.

Learning objectives

  • Apply the multiplication rule
  • Compute a factorial and an arrangement
  • Say whether order matters in a given situation
