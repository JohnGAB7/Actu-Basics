Our purpose

Making quantitative ideas easier to understand.

ACTU-BASICS is an independent educational project about statistics, probability and actuarial science.

Enlightening through numbers.

Numbers shape decisions, risk, economic phenomena and everyday life. Yet their meaning depends on the methods used to produce and interpret them.

ACTU-BASICS aims to make these methods understandable without sacrificing rigour. Each concept should be explained clearly, illustrated with an example and grounded in its assumptions.

A three-step learning approach

01 · UNDERSTAND

A clear explanation

Start with a question and build intuition before technique.

02 · EXPLORE

An explicit method

Show definitions, formulas, assumptions and limitations.

03 · PRACTISE

A concrete example

Apply the method, check the result and understand what it means.

A project that grows progressively

Videos and the website complement each other. Videos introduce ideas; the website organises lessons and resources so learners can revisit the reasoning and practise.

Content is published as it is prepared and reviewed. A resource is shown as available only when it is genuinely accessible.
