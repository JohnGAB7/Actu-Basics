S4-06

Le paradoxe des anniversaires

Dans un groupe de 23 personnes, quelle est la probabilité que deux partagent le même anniversaire ? L'intuition dit « vraiment très peu », mais la bonne réponse dépasse 50 %. L'astuce : on ne compte pas les 22 paires qui nous concernent personnellement, mais les 253 paires du groupe entier. Et on passe par le complément « tous différents ». Exercice corrigé à la fin. Données fictives. Série « Lire un chiffre sans se faire avoir ».

Vidéos · Vidéo en préparation

Objectifs

  • Compter les paires d'un groupe par la formule n(n−1)/2
  • Calculer la probabilité que tous les anniversaires soient différents, puis passer par le complément
  • Expliquer pourquoi l'intuition se trompe

Prérequis

  • S4.04 : combinaisons
  • S4.05 : complément et union

23 personnes dans une pièce : 2 partagent un anniversaire ?

Vingt-trois personnes dans une pièce. Quelle est la probabilité que deux partagent la même date de naissance, jour et mois ? Beaucoup répondent « quelques pour cent ». La bonne réponse, dans le modèle classique, dépasse cinquante pour cent.

Pourquoi l'intuition se trompe

D'abord, comprendre où va de travers l'intuition.

Ce que vous comptez, ce que le groupe compte

Chacun, instinctivement, pense aux vingt-deux paires qu'il forme avec les autres. Mais la question ne porte pas sur vous : elle porte sur une coïncidence dans tout le groupe. Et le groupe, c'est deux cent cinquante-trois paires, pas vingt-deux.

  • Vous : vos 22 paires avec les autres
  • Le groupe : toutes les paires possibles
  • C(23, 2) = 253 paires

Nombre de paires = n(n − 1) / 2

C'est la formule du nombre de paires dans un groupe de n personnes : n fois n moins un, divisé par deux. Pour vingt-trois : vingt-trois fois vingt-deux sur deux, deux cent cinquante-trois.

nb_paires(n) = n × (n - 1) / 2

La méthode : passer par le complément

Compter les coïncidences directement serait pénible. On passe par le contraire : tous différents.

P(tous différents) = 365/365 × 364/365 × … × 343/365

La première personne prend un anniversaire parmi trois cent soixante-cinq jours : trois cent soixante-cinq sur trois cent soixante-cinq. La deuxième doit tomber sur un jour différent : trois cent soixante-quatre sur trois cent soixante-cinq. La troisième, sur un des trois cent soixante-trois jours restants. Et ainsi de suite jusqu'à la vingt-troisième. On multiplie tous ces rapports.

P(tous diff) = prod((365 - k) / 365 for k in range(n))

Le calcul pour 23 personnes

Appliquons.

Résultat pour n = 23

Le produit vaut environ zéro virgule quatre cent quatre-vingt-treize. Son complément, c'est-à-dire la probabilité d'au moins un partage, vaut un moins cela : zéro virgule cinq cent sept. Cinquante virgule sept pour cent. À partir de vingt-trois personnes, c'est déjà plus probable que pas.

  • P(tous différents) ≈ 0,493
  • P(au moins un partage) = 1 − 0,493
  • ≈ 0,507, soit 50,7 %

Que se passe-t-il quand n augmente ?

Et avec plus de personnes ?

La probabilité monte très vite

À trente personnes, soixante-dix pour cent. À quarante, presque neuf chances sur dix. À cinquante, quatre-vingt-dix-sept pour cent. Quand n grandit, le nombre de paires croît en n au carré : on finit par en avoir tellement qu'une coïncidence devient presque certaine.

  • n = 23 : 50,7 %
  • n = 30 : 70,6 %
  • n = 40 : 89,1 %
  • n = 41 : 90,3 %
  • n = 50 : 97,0 %

Deux erreurs à éviter

Deux pièges.

Les deux erreurs classiques

Première erreur : calculer vingt-trois divisé par trois cent soixante-cinq. C'est la probabilité qu'une personne particulière partage précisément votre anniversaire, pas celle d'une coïncidence quelque part dans le groupe. Seconde erreur : croire que les deux cent cinquante-trois paires sont indépendantes. Elles ne le sont pas : si A et B ont la même date, et A et C aussi, alors B et C l'ont aussi.

  • Croire qu'il faut calculer 23 / 365 : c'est la probabilité qu'une personne précise partage votre anniversaire
  • Croire que les paires sont indépendantes : elles ne le sont pas

À vous

À vous.

Exercice

À partir de combien de personnes la probabilité d'un partage dépasse-t-elle 90 % ?

À partir de combien de personnes la probabilité d'au moins un anniversaire partagé dépasse-t-elle quatre-vingt-dix pour cent ? Pause.

Correction

À quarante personnes, on est à quatre-vingt-neuf pour cent : pas encore. À quarante et une, quatre-vingt-dix virgule trois pour cent : c'est bon. La réponse est quarante et une personnes.

  • On cherche le plus petit n tel que 1 − P(tous différents) ≥ 0,9
  • n = 40 : 89,1 % (pas encore)
  • n = 41 : 90,3 % — ça y est
  • Réponse : 41 personnes
Réponse : 41 personnes

À retenir

À retenir. Dans un groupe de n personnes, il y a n fois n moins un divisé par deux paires, et non n paires. Pour la probabilité d'au moins un anniversaire partagé, on passe par « tous différents » et on prend le complément. Et l'intuition se trompe parce qu'on ne compte que les paires qui nous concernent.

  • Les paires d'un groupe de n : n(n − 1) / 2
  • Passer par le complément tous différents
  • L'intuition ne compte pas toutes les paires
