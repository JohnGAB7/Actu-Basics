Simuler le hasard : la fréquence se stabilise.

Lancer une pièce dix fois, puis dix mille fois : que se passe-t-il ? Le hasard est imprévisible au coup par coup, mais très régulier en grand nombre. Une simulation permet d'observer la fréquence de pile se rapprocher de cinquante pour cent et d'estimer une probabilité difficile à calculer exactement.

Objectifs pédagogiques

  • Décrire comment la fréquence observée se stabilise quand n augmente
  • Utiliser une simulation pour estimer une probabilité
