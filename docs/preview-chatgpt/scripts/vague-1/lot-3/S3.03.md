## Description FR (YouTube, TikTok)

Un traitement réussit mieux que l'autre chez les patients à petits
calculs rénaux, et mieux aussi chez ceux à gros calculs. Pourtant, au
total, c'est l'autre qui semble gagner. Comment est-ce possible ? Avec
les chiffres d'une étude médicale d'observation de 1986, on reproduit le
paradoxe de Simpson et on comprend le rôle d'une variable de confusion.
Source : C. R. Charig et coll., British Medical Journal, 1986. Exercice
corrigé (hôpitaux fictifs). Série « Lire un chiffre sans se faire avoir
».

## Calculs recalculés par la machine

- Taux de succès total, A (%) : `100 × 273 / 350` = 78
- Taux de succès total, B (%) : `100 × 289 / 350` = 83
- A, petits calculs (%) : `100 × 81 / 87` = 93
- B, petits calculs (%) : `100 × 234 / 270` = 87
- A, gros calculs (%) : `100 × 192 / 263` = 73
- B, gros calculs (%) : `100 × 55 / 80` = 69
- Succès de A, total : `81 + 192` = 273
- Succès de B, total : `234 + 55` = 289
- Patients du traitement A : `87 + 263` = 350
- Patients du traitement B : `270 + 80` = 350
- H1, légers (%) : `100 × 90 / 100` = 90
- H2, légers (%) : `100 × 340 / 400` = 85
- H1, graves (%) : `100 × 300 / 400` = 75
- H2, graves (%) : `100 × 70 / 100` = 70
- H1, total (%) : `100 × (90 + 300) / 500` = 78
- H2, total (%) : `100 × (340 + 70) / 500` = 82

## Description EN

One treatment works better than another for patients with small kidney
stones, and better for those with large ones too. Yet overall, the other
treatment seems to win. How is that possible? Using the figures from a
1986 observational medical study, we reproduce Simpson's paradox and see
the role of a confounding variable. Source: C. R. Charig et al., British
Medical Journal, 1986. Worked exercise (fictional hospitals). Series
"Reading numbers without being fooled".
