## Calculs recalculés par la machine

- Present value of \$1,000 in 30 years at 5%: `1000 / 1.05^30` = 231.38
- Check: `231.38 × 1.05^30` = 1000
- Present value at 2%: `1000 / 1.02^30` = 552
- Present value at 5%: `1000 / 1.05^30` = 231
- Present value at 8%: `1000 / 1.08^30` = 99
