# ACTU-BASICS · Vague 1, lot 3 · Scripts relus, à valider par JG

Dix nouveaux épisodes, de S2.06 à S3.05, en FR et en EN. Aucune vidéo n'a été rendue. La relecture de ChatGPT du 2026-11-09 (commentaires de la PR #17) est intégrée ; reste la validation de JG.

Chaque script contient : fiche d'identité, points à trancher, script FR scène par scène (à l'écran, voix off), script EN, description, sources et calculs recalculés par la machine.

Nouveautés du moteur : boîtes à moustaches (atypiques compris), utilisées dans S2.06, S2.07, S2.09 et S3.01 ; nuages de points avec axes cadrés et point mis en avant, dans S3.04 et S3.05.

Exemples remplacés : le catalogue proposait trois exemples réels sans source (rapport D9/D1 d'un pays, Brest et Strasbourg, PIB et espérance de vie). Ils sont remplacés par des exemples fictifs, annoncés comme tels. Deux exemples réels sont gardés et sourcés : l'étude des calculs rénaux de Charig et coll. (BMJ, 1986) pour S3.03, présentée comme une étude d'observation (ChatGPT a confirmé les totaux sur l'article), et le quartet d'Anscombe (1973) pour S3.05, dont les quatre corrélations sont recalculées par la machine.

Les durées sont des estimations à partir du nombre de mots. Comme pour le lot 2, elles sont souvent sous la fourchette du programme. Les fiches de production (source de vérité, format YAML) sont dans `contenus/fiches/`.
