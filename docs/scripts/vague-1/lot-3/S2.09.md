  que le calcul affiché soit juste.

## Calculs recalculés par la machine

- Écart interquartile (m) : `1.80 - 1.65` = 0.15
- Frontière haute (m) : `1.80 + 1.5 × 0.15` = 2.025
- Frontière basse (m) : `1.65 - 1.5 × 0.15` = 1.425
