## Calculs recalculés par la machine

- Un million de secondes, en jours : `1e6 / 86400` = 11.6
- Un milliard divisé par un million : `1e9 / 1e6` = 1000
- Un milliard de secondes, en années : `1e9 / (365.25 × 86400)` = 31.7
- 4,5 × 10⁴ : `4.5 × 10^4` = 45000
- 3 × 10⁻³ : `3 × 10^-3` = 0.003
- Rapport des deux budgets : `3e9 / 2e6` = 1500
- 3 millions / 2 millions : `3e6 / 2e6` = 1.5
- 3 milliards / 3 millions : `3e9 / 3e6` = 1000
- Billion français / milliard : `1e12 / 1e9` = 1000
- 5,2 × 10⁷ : `5.2 × 10^7` = 52000000
