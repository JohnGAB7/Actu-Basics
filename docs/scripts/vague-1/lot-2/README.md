# ACTU-BASICS · Vague 1, lot 2 · Scripts à relire

Dix épisodes, de S1.08 à S2.05. S1.08 et S2.05 sont les vidéos pilotes déjà validées par JG : elles sont incluses pour la cohérence du lot et ne sont pas modifiées. Les huit autres scripts (S1.09 à S2.04) sont nouveaux, en FR et en EN, et aucune vidéo n'a été rendue.

Chaque script contient : fiche d'identité, points à trancher, script FR scène par scène (à l'écran, voix off), script EN, description, sources et calculs recalculés par la machine.

Nouveauté du moteur : diagrammes en barres et histogrammes (classes inégales comprises), utilisés dans S2.01, S2.02 et S2.03.

Les durées sont des estimations à partir du nombre de mots. Plusieurs scripts sont plus courts que la fourchette du programme : c'est signalé dans leurs points à trancher.

Relecture : commentaires sur la PR #17. Les fiches de production (source de vérité, format YAML) sont dans `contenus/fiches/`.
