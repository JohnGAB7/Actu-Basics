<li>Le plus honnête : donner les deux</li>
</ul></td>
<td>Chaque indicateur répond à sa propre question. Pour savoir ce que gagne un salarié typique, la médiane est la bonne réponse. Pour savoir combien coûtent tous les salaires ensemble, il faut la moyenne, multipliée par le nombre de salariés : la médiane ne le permet pas. Le plus honnête est souvent de donner les deux, car l'écart entre elles dit à lui seul si la distribution est asymétrique.</td>

## Calculs recalculés par la machine

- Somme des 9 salaires : `1600 + 1800 + 1900 + 2000 + 2200 + 2300 + 2500 + 2700 + 2800` = 19800
- Moyenne des 9 salaires : `19800 / 9` = 2200
- Moyenne des 10 salaires : `(19800 + 200000) / 10` = 21980
- Part des clients sous la moyenne, en % : `100 × 9 / 10` = 90
- Position du milieu, 9 valeurs : `(9 + 1) / 2` = 5
- Position du milieu, 10 valeurs : `(10 + 1) / 2` = 5.5
- Médiane des 10 salaires : `(2200 + 2300) / 2` = 2250
- Hausse de la médiane, en euros : `2250 - 2200` = 50
- Moyenne des dix salaires du graphique : `(1600 + 1800 + 1900 + 2000 + 2200 + 2300 + 2500 + 2700 + 2800 + 200000) / 10` = 21980
- Somme des 7 salaires : `1500 + 1600 + 1700 + 1800 + 1900 + 2000 + 2100` = 12600
- Moyenne des 7 salaires : `12600 / 7` = 1800
- Moyenne des 8 salaires : `(12600 + 20000) / 8` = 4075
- Médiane des 8 salaires : `(1800 + 1900) / 2` = 1850
