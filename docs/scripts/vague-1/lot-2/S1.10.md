## Description FR (YouTube, TikTok)

Enlever le nom d'un fichier ne suffit pas à le rendre anonyme. Date de naissance, sexe et code postal : croisées, ces trois colonnes rendent la plupart des gens uniques. On voit la différence entre pseudonymiser et anonymiser, on calcule pourquoi chaque colonne ajoutée isole davantage chaque ligne, et on découvre trois bonnes pratiques pour publier des données sans exposer personne. Source : L. Sweeney, Carnegie Mellon University, 2000. Série « Lire un chiffre sans se faire avoir ».

## Calculs recalculés par la machine

- 216 millions sur 248 millions, en % : `216 / 248 × 100` = 87
- Combinaisons mois × sexe × service : `12 × 2 × 10` = 240
- Salariés par combinaison : `500 / 240` = 2.1
- Cases de la grille : `12 × 2 × 10` = 240

## Description EN

Removing the name from a file isn't enough to make it anonymous. Date of birth, sex and postcode: combined, these three columns make most people unique. We see the difference between pseudonymising and anonymising, work out why every extra column isolates each row a bit more, and learn three good practices for publishing data without exposing anyone. Source: L. Sweeney, Carnegie Mellon University, 2000. Series "Reading numbers without being fooled".
