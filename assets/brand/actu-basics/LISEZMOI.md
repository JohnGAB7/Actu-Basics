## Règles

- Ne jamais remplacer ces fichiers par une reconstitution, une version générée ou retouchée.
- Le moteur de rendu ne fait que les **réduire proportionnellement** : aucun étirement, aucun recadrage, aucune recoloration, aucun effet.
- Le moteur cherche d'abord `logo-dark.webp` et `logo-light.webp` (noms du guide de marque), puis les `.png`. Pour mettre à jour un logo, déposer le nouveau fichier officiel sous l'un de ces noms. Aucun code n'est à modifier.
- S'il manque un fichier, rien n'est dessiné à sa place et le rendu final est refusé.
- Au-delà de la largeur du fichier (1182 px), le logo serait agrandi et flou : le rapport le signale.
- Le slogan du logo est en français. Dans la version anglaise, le slogan « Enlightening through numbers. » est écrit sous le logo.
