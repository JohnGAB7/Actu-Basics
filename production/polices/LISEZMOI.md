# Polices

- `Anton-Regular.ttf` : police d'affichage (accroches, chiffres, titres). Licence SIL Open Font License 1.1 (`OFL-Anton.txt`), source : https://github.com/google/fonts/tree/main/ofl/anton
- Inter (texte courant) : non incluse ici, installée sur la machine (paquet Linux `fonts-inter`, ou https://rsms.me/inter/).

Toute autre police déposée ici est utilisée en priorité si elle est citée dans `production/charte.yaml`. Vérifier sa licence avant de l'ajouter au dépôt.
